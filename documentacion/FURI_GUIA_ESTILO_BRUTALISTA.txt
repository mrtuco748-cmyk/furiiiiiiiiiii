═══════════════════════════════════════════════════════════════════════════════
1. PRINCIPIO FUNDAMENTAL: CAOS ORGANIZADO
═══════════════════════════════════════════════════════════════════════════════

Cada pantalla usa Stack + Positioned con bloques de distintos tamanos,
posiciones libres, y ligeras rotaciones. NO se usan GridView, Table,
Column, Row para el layout principal. Los bloques se posicionan
manualmente formando un "caos ordenado" -- dispersos pero intencionales.

═══════════════════════════════════════════════════════════════════════════════
2. REGLAS VISUALES DE skill_visual .md (OBLIGATORIAS)
═══════════════════════════════════════════════════════════════════════════════

Las siguientes reglas de skill_visual .md tienen prioridad absoluta sobre
cualquier otra regla visual:

2.1. Fondo y Borde del Mismo Color
  - Todo elemento con borde y fondo debe tener IDENTICO color en ambos.
  - Fondo SIEMPRE solido (Opacity 1.0), NUNCA transparente ni con alpha.
  - PROHIBIDO: fondos transparentes, rgba con alpha < 1, o semi-transparentes.
  - PROHIBIDO: color de borde diferente al color de fondo.
  - PROHIBIDO: usar negro puro (#000000) como color de fondo.

2.2. Bordes Redondos
  - Todo elemento con borde y fondo de color debe tener border-radius.
  - Bloques grandes (cards, paneles): borderRadius: 16-24 (heredado: 18)
  - Botones, tags: borderRadius: 6-12
  - Popups, modales: borderRadius: 16-24
  - PROHIBIDO: BorderRadius.zero en elementos con borde y fondo de color.

2.3. Sin Sombras
  - PROHIBIDO: boxShadow, elevation, drop shadows de cualquier tipo.
  - boxShadow: NONE en todos los elementos.

2.4. Sin Degradados
  - PROHIBIDO: linear-gradient, radial-gradient, sweep-gradient.
  - Fondos SIEMPRE de color solido.

2.5. Principios Brutalistas que se Mantienen
  - Tipografia monoespaciada (monospace).
  - Layouts crudos y asimetricos bienvenidos.
  - Sin sombras (boxShadow: none).
  - Sin degradados.
  - Paleta de colores limitada y saturada.
  - Sin adornos decorativos innecesarios.

4. ESTRUCTURA BASE DE CADA PANTALLA (TEMPLATE)
═══════════════════════════════════════════════════════════════════════════════

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import '../widgets/tap_tile.dart';
import '../widgets/concrete_painter.dart';

const _c = Color(0xFFxxxxxx); // color de la seccion

class XxxScreen extends StatelessWidget {
  const XxxScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: const Color(0xFF0A0A0A),
      body: Stack(
        children: [
          const Positioned.fill(child: CustomPaint(painter: ConcretePainter())),
          SafeArea(child: LayoutBuilder(
            builder: (context, constraints) {
              final w = constraints.maxWidth;
              final h = constraints.maxHeight;
              return Stack(children: [
                // Bloques posicionados libremente
                // ...
                _header(context),
              ]);
            },
          )),
        ],
      ),
    );
  }
}

5. BLOQUES (COMPONENTE ATOMICO) — ACTUALIZADO skill_visual
═══════════════════════════════════════════════════════════════════════════════

Cada bloque se define como:

  Positioned(left: x, top: y, width: w, height: h,
    child: TapTile(
      onTap: () => onTap(x + w/2, y + h/2),
      child: ClipRRect(
        borderRadius: BorderRadius.circular(18),
        child: Container(
          decoration: BoxDecoration(
            color: backgroundColor,           // SOLIDO, sin alpha
            border: Border.all(
              color: backgroundColor,          // IGUAL al color de fondo
              width: borderWidth,
            ),
            borderRadius: BorderRadius.circular(18),
            // SIN boxShadow
          ),
          child: childWidget,
        ),
      ),
    ),
  );

Reglas de bloques (actualizadas skill_visual):
- borderRadius: SIEMPRE 18 (herencia del HomeScreen)
- backgroundColor: color SOLIDO (Opacity 1.0), NUNCA con alpha < 1
- borderColor: SIEMPRE IGUAL al backgroundColor
- borderWidth: variable entre 2-6px, segun jerarquia visual
- SIN boxShadow
- Todo tap usa HapticFeedback (lightImpact, mediumImpact, selectionClick)
- Rotaciones: -0.1 a 0.1 radianes con Transform.rotate

Colores de bloque validos:
- _c directamente (color vibrante puro)
- Variante oscura de _c (con .withBlue, .withGreen, .withRed para oscurecer, NUNCA con alpha)
- Colores neutros solidos (#1a1a1a, #2d2d2d, #3a3a3a, etc.)
- PROHIBIDO: _c.withValues(alpha: 0.xx)

- boton volver: fondo #1a1a1a (NUNCA negro puro #000000)
- boton volver: borde = mismo color que fondo
- boton volver: borderRadius definido (NO BorderRadius.zero)

7. FONDO CONCRETEPAINTER — ACTUALIZADO skill_visual
═══════════════════════════════════════════════════════════════════════════════

CustomPainter _ConcretePainter:
- Fondo solido gris oscuro (#1a1a1a), SIN gradientes
- 80 puntos de ruido blanco aleatorio (opacidad 1.5%, tamano 1-5px)
- 12 lineas horizontales finas (opacidad 4%, 0.5px de grosor)
- Seed Random: 42 (reproducible)

Cambios respecto a version anterior:
- ELIMINADO el gradiente lineal diagonal (viola regla "sin degradados")
- Fondo: color solido #1a1a1a en lugar de gradiente multi-stop

═══════════════════════════════════════════════════════════════════════════════
8. TIPOGRAFIA
═══════════════════════════════════════════════════════════════════════════════

- Fuente: SIEMPRE 'monospace'
- Peso: FontWeight.bold para titulos, FontWeight.w900 para destacados
- Color de texto: _c (el color de la seccion) o blanco/gris claro
- Texto sobre fondo oscuro: Colors.white o Color(0xFFCCCCCC)
- Tamanos: proporcionales al ancho de pantalla (w * factor)

9. INTERACCIONES
═══════════════════════════════════════════════════════════════════════════════

- TapTile: animacion scale 1.0 -> 1.12 -> 0.95 -> 1.0 (150ms)
- HapticFeedback en CADA tap
- Confeti al navegar entre pantallas (desde HomeScreen)
- Transiciones de pagina: MaterialPageRoute (default)
- Sin animaciones suaves >200ms

═══════════════════════════════════════════════════════════════════════════════
10. PROCESO PARA CREAR UNA NUEVA PANTALLA
═══════════════════════════════════════════════════════════════════════════════

1. Elegir _c (color de seccion)
2. Disenar layout unico: 5-8 bloques con posiciones/tamanos/rotaciones distintas
3. Cada bloque tiene un proposito funcional (icono, texto, widget anidado)
4. Al menos 2 bloques con rotacion distinta
5. Al menos 3 tamanos de bloque diferentes
6. Header con boton volver (con borderRadius, sin negro puro)
7. ConcretePainter de fondo (sin gradientes)
8. Verificar checklist de skill_visual .md antes de mergear

NO USAR: GridView, Table, Row, Column como layout principal.
USAR: Stack + Positioned con calculos desde LayoutBuilder.
